# Making pictures with Gemini ("Nano Banana")

Ask Claude for a dish or ingredient picture and it runs `tangled-taste/scripts/gemini-image.mjs`, which calls the Gemini image API, saves the picture in the right folder, and (when you ask) commits and pushes it. The next site build turns it into the thumbnails, previews and icons you see on the site. No code changes are needed.

## One-time setup (about two minutes)

1. Get a Gemini API key from Google AI Studio (https://aistudio.google.com/apikey). Image generation needs billing enabled on the key's project; each picture costs a few cents.
2. Create the file `tangled-taste/.env.local` on your computer with one line:

   ```
   GEMINI_API_KEY=paste-your-key-here
   ```

   This file is listed in `.gitignore`, so it is never uploaded to GitHub. **Do not paste the key into the chat**; Claude only needs the file to exist.
3. That is all. (The default model is `gemini-2.5-flash-image`. To use another, set `GEMINI_IMAGE_MODEL=...` in the same file, or pass `--model` to the script.)

## What to ask Claude

- "Make the picture for Birria Tacos." / "Make a picture for TT-0650."
- "Make an ingredient picture for yam."
- "Make pictures for the 10 most popular dishes that don't have one."
- "Redo Pad Thai, but show it in a blue-and-white bowl." (adds an extra instruction to the prompt)
- "Publish them." (Claude commits and pushes; GitHub rebuilds the site.)

Claude shows you the pictures first if you ask to review them, and only pushes when you say so.

## Where things go

| What | Source picture | Prompt you can edit |
|---|---|---|
| Dishes | `tangled-taste/art/dishes/TT-0650.webp` (the dish's permanent ID) | `tangled-taste/art/prompts/dish.md` |
| Ingredients | `tangled-taste/art/ingredients/olive-oil.webp` (name, lower case, hyphens) | `tangled-taste/art/prompts/ingredient.md` |

- Source pictures are 1024 x 1024 WebP with a plain white background. The site build (`pnpm art:build`, run automatically by `pnpm dev` and `pnpm build` and by the GitHub deploy) removes the white, centers the subject and makes the thumbnails; dishes also get a large preview for the Detail Pane.
- An ingredient without a picture keeps the painting drawn in code; a dish without one shows a plain blob. A picture replaces that automatically as soon as its file exists.
- To change a picture later, replace the file (same name) or ask Claude to redo it with `--force`.

## Command line (if you want to run it yourself)

```
cd tangled-taste
node scripts/gemini-image.mjs dish "Birria Tacos"
node scripts/gemini-image.mjs ingredient "olive oil"
node scripts/gemini-image.mjs dishes --limit 10        # most popular dishes with no picture yet
node scripts/gemini-image.mjs ingredients --limit 10   # most used ingredients with no picture yet
```

Add `--dry-run` to see the prompt without calling the API, `--force` to replace an existing picture, `--extra "text"` to add to the prompt.

## Good to know

- Pictures are generated by an AI model: results vary, so look at each one. A note appears when a picture's subject runs to the edge of the image; ask for a redo with more margin.
- Prompts (the dish's name, cuisine, notes and main ingredients) are sent to Google. Nothing else is.
- If the Google API changes its model names, update `GEMINI_IMAGE_MODEL`; the script reports what Google said when a request fails.
