# Welcome to Tangled Taste!

Visually explore the relationships between cuisines, dishes, and ingredients.

Three things to know before getting started:

1. There is an Ingredient Mode (default) and Dish Mode - use the toggle at the top to switch.
2. Check out "Settings" to tweak the visual display - some of these make it easier to visualize the data.
3. This is a personal project and work in progress - feedback is welcome.
